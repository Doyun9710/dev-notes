# Computer Systems

컴퓨터 시스템의 동작 원리를 개발자 관점에서 이해하기 위한 학습 기록.

## 학습 목적

- 프로그램이 소스 코드에서 실행되기까지의 과정 이해
- 데이터가 컴퓨터 내부에서 표현되고 처리되는 방식 이해
- CPU, 메모리, 운영체제 등 시스템 구성 요소의 동작 원리 학습
- 시스템 지식을 실제 개발 경험 및 문제 해결과 연결
- 단순한 교재 요약이 아닌, 직접 이해한 내용을 중심으로 기록

## 기준 교재

**Computer Systems: A Programmer's Perspective, 3rd Edition**

- Randal E. Bryant
- David R. O'Hallaron

교재의 목차와 전개 순서를 따라 학습하되, 내용을 그대로 번역하거나 요약하지 않고 개발자의 관점에서 재구성하여 정리.

## 작성 방식

- 한 문서에서 하나의 핵심 주제를 중심으로 학습
- 개념의 정의보다 동작 원리와 이유를 중심으로 정리
- 필요한 경우 C 코드, Assembly, Linux 명령어 등을 직접 실행하여 확인
- 실제 개발에서 해당 개념이 중요한 이유 포함
- 내용이 많아질 경우 하나의 Chapter라도 여러 문서로 분리
- 각 문서는 GitHub Markdown과 Velog 게시를 함께 고려하여 작성
