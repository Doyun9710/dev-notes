# 2.1.7 C에서 비트 수준 연산하기

> Bit-Level Operations in C

## 핵심 개념

* 앞 절에서 불 대수를 이용해 비트에 적용할 수 있는 연산 확인
* C에서는 이러한 연산을 직접 수행할 수 있는 **비트 수준 연산자(Bitwise Operator)** 제공

```text
Boolean Algebra
      ↓
NOT / AND / OR / XOR
      ↓
C Bitwise Operators
      ↓
~  &  |  ^
```

* 정수값을 하나의 비트 벡터로 보고 각 비트 위치에 독립적으로 Boolean 연산 적용

---

## C의 비트 연산자

C에서 사용하는 주요 비트 연산자:

| 연산  | C 연산자 | 의미                 |                  |
| --- | ----- | ------------------ | ---------------- |
| NOT | `~`   | 각 비트 반전            |                  |
| AND | `&`   | 두 비트가 모두 `1`이면 `1` |                  |
| OR  | `     | `                  | 하나 이상이 `1`이면 `1` |
| XOR | `^`   | 두 비트가 서로 다르면 `1`   |                  |

예:

```c
unsigned int x;
unsigned int y;

~x;
x & y;
x | y;
x ^ y;
```

* `char`, `short`, `int`, `long`, `long long` 등의 정수 타입에 적용 가능
* signed / unsigned 정수 모두 사용 가능

다만 실제 연산에서는 C의 **정수 승격(Integer Promotion)** 과 타입 변환 규칙이 적용됨.

---

## 비트별 연산 방식

두 8비트 패턴을 가정.

```text
x = 0100 0001
y = 0101 0101
```

각 비트 위치별로 독립적으로 연산 수행.

### AND

```text
  0100 0001
& 0101 0101
-----------
  0100 0001
```

16진수:

```text
0x41 & 0x55
=
0x41
```

---

### OR

```text
  0100 0001
| 0101 0101
-----------
  0101 0101
```

16진수:

```text
0x41 | 0x55
=
0x55
```

---

### XOR

```text
  0100 0001
^ 0101 0101
-----------
  0001 0100
```

16진수:

```text
0x41 ^ 0x55
=
0x14
```

---

## NOT과 정수 승격

8비트 값:

```text
0100 0001
```

만 대상으로 Boolean NOT을 수행하면:

```text
0100 0001
    ↓
1011 1110
```

즉:

```text
0xBE
```

하지만 C 코드에서는 한 가지 주의점 존재.

```c
unsigned char x = 0x41;

~x;
```

`unsigned char`에 직접 8비트 NOT을 수행하는 것처럼 보이지만, C에서는 일반적으로 연산 전에 `x`가 `int`로 승격됨.

```text
unsigned char

0x41
   ↓ Integer Promotion

int

0x00000041
```

32비트 `int`를 가정하면:

```text
  00000000 00000000 00000000 01000001
~
------------------------------------------------
  11111111 11111111 11111111 10111110
```

따라서 결과는:

```text
0xFFFFFFBE
```

에 해당.

하위 8비트 결과만 원한다면 명시적인 변환 가능.

```c
unsigned char result = (unsigned char) ~x;
```

결과:

```text
0xBE
```

또는 마스크 사용 가능.

```c
~x & 0xFF
```

결과:

```text
0xBE
```

> 비트 연산은 비트 수준에서 동작하지만 C의 타입 변환 규칙보다 먼저 동작하는 것은 아님.

---

## 비트 연산에서는 unsigned 타입이 유용함

signed 정수에도 비트 연산자를 적용할 수 있지만, 비트 패턴 자체를 다루는 코드에서는 unsigned 타입이 일반적으로 이해하기 쉬움.

```c
unsigned int flags;
```

* 부호에 따른 해석을 피할 수 있음
* 비트 마스크의 의미가 명확해짐
* 이후 shift 연산에서도 signed 타입보다 동작을 이해하기 쉬움

따라서 시스템 프로그래밍에서 다음과 같은 형태를 자주 사용.

```c
unsigned int mask;
uint32_t flags;
uint8_t byte;
```

---

## 마스크 — Mask

**마스크(Mask)** 는 원하는 비트만 선택하거나 변경하기 위해 사용하는 특정 비트 패턴.

```text
Data
   ↓
Mask
   ↓
Bitwise Operation
   ↓
Selected / Modified Bits
```

대표적인 활용:

```text
특정 비트 추출
특정 비트 설정
특정 비트 제거
특정 비트 반전
```

---

## 특정 비트만 추출하기 — AND

AND의 중요한 성질:

```text
x & 1 = x
x & 0 = 0
```

따라서 마스크에서:

* `1`인 위치 → 원래 비트 유지
* `0`인 위치 → 비트 제거

예:

```text
x    = 1010 1101
mask = 0000 1111
```

AND:

```text
  1010 1101
& 0000 1111
-----------
  0000 1101
```

* 하위 4비트만 추출

---

## 하위 바이트 추출

더 넓은 정수 `x`에서 하위 8비트만 남기려면:

```c
x & 0xFF
```

마스크:

```text
0x000000FF

00000000 00000000 00000000 11111111
```

예:

```text
x = 0x12345678
```

연산:

```text
0x12345678
&
0x000000FF
------------
0x00000078
```

결과:

```text
0x78
```

* 상위 비트는 모두 `0`
* 최하위 8비트만 유지

> `0xFF`의 의미는 연산 대상의 크기에 따라 판단해야 함. 이미 8비트 값이라면 전체 비트를 선택하는 마스크가 됨.

---

## 특정 비트를 1로 설정하기 — OR

OR의 성질:

```text
x | 0 = x
x | 1 = 1
```

따라서 마스크에서:

* `0`인 위치 → 기존 값 유지
* `1`인 위치 → 무조건 `1`

예:

```text
x    = 1010 1100
mask = 0000 0001
```

연산:

```text
  1010 1100
| 0000 0001
-----------
  1010 1101
```

C 코드:

```c
x | 0x01
```

* 최하위 비트(Least Significant Bit)를 `1`로 설정

---

## 특정 비트를 반전하기 — XOR

XOR의 성질:

```text
x ^ 0 = x
x ^ 1 = ~x
```

따라서 마스크에서:

* `0`인 위치 → 기존 값 유지
* `1`인 위치 → 비트 반전

예:

```text
x    = 1010 1100
mask = 0000 0101
```

연산:

```text
  1010 1100
^ 0000 0101
-----------
  1010 1001
```

* 마스크가 `1`인 위치만 반전

이를 **toggle** 연산으로 활용 가능.

---

## 특정 비트를 0으로 만들기

특정 위치의 비트를 제거하려면 AND와 NOT을 함께 사용 가능.

예를 들어 비트 2를 `0`으로 만들고 싶다면:

```c
x & ~(1u << 2)
```

개념적으로:

```text
0000 0100     ← 제거할 위치
     ↓ NOT
1111 1011
```

AND:

```text
original
&
1111 1011
```

* 선택한 위치만 `0`
* 나머지 비트는 유지

이는 이후 shift 연산까지 학습하면 더 자연스럽게 이해 가능.

---

## 비트 마스크의 대표 패턴

비트 연산의 핵심 성질을 정리하면:

| 목적       | 연산  | 마스크 비트 |     |
| -------- | --- | ------ | --- |
| 비트 유지/추출 | `&` | `1`    |     |
| 비트 제거    | `&` | `0`    |     |
| 비트 설정    | `   | `      | `1` |
| 비트 유지    | `   | `      | `0` |
| 비트 반전    | `^` | `1`    |     |
| 비트 유지    | `^` | `0`    |     |

즉:

```text
AND → 선택
OR  → 설정
XOR → 반전
```

이라는 관점으로 이해 가능.

---

## XOR의 중요한 성질

XOR에는 다음과 같은 성질 존재.

```text
x ^ x = 0
```

동일한 값끼리 XOR하면 모든 비트가 같으므로 결과는 `0`.

또한:

```text
x ^ 0 = x
```

그리고:

```text
(x ^ y) ^ y = x
```

XOR는 결합 법칙과 교환 법칙도 만족.

```text
x ^ y = y ^ x
```

```text
(x ^ y) ^ z
=
x ^ (y ^ z)
```

이러한 성질을 이용한 대표적인 예가 XOR swap.

---

## XOR를 이용한 값 교환

일반적인 값 교환:

```c
int temp = *x;
*x = *y;
*y = temp;
```

XOR의 성질을 이용하면 임시 변수 없이 교환 가능.

```c
void inplace_swap(int *x, int *y) {
    *y = *x ^ *y;
    *x = *x ^ *y;
    *y = *x ^ *y;
}
```

초기값을:

```text
*x = A
*y = B
```

라고 가정.

### Step 1

```c
*y = *x ^ *y;
```

결과:

```text
*x = A
*y = A ^ B
```

### Step 2

```c
*x = *x ^ *y;
```

대입하면:

```text
*x = A ^ (A ^ B)
```

XOR 성질:

```text
A ^ A = 0
0 ^ B = B
```

따라서:

```text
*x = B
*y = A ^ B
```

### Step 3

```c
*y = *x ^ *y;
```

대입:

```text
*y = B ^ (A ^ B)
```

결과:

```text
*y = A
```

최종적으로:

```text
*x = B
*y = A
```

* 임시 변수 없이 두 값의 교환 완료

---

## XOR Swap의 문제점

XOR swap은 두 포인터가 서로 다른 객체를 가리킨다는 전제 필요.

다음 호출을 생각하면:

```c
int a = 10;

inplace_swap(&a, &a);
```

`x`와 `y`가 같은 주소를 가리킴.

첫 번째 연산:

```c
*y = *x ^ *y;
```

실제로는:

```text
a = a ^ a
```

따라서:

```text
a = 0
```

이후 모든 연산에서도 값은 계속 `0`.

결과:

```text
10
↓
0
```

* 두 인자가 같은 메모리 위치를 가리키면 원래 값 손실
* **Aliasing**이 있을 때 잘못 동작하는 대표적인 사례

---

## XOR Swap은 학습용 예제에 가까움

XOR swap은 XOR의 성질을 이해하기에는 좋은 예제.

```text
x ^ x = 0
x ^ 0 = x
```

하지만 일반적인 프로그램에서는 다음 방식이 더 적절.

```c
int temp = *x;
*x = *y;
*y = temp;
```

이유:

* 코드 의도가 명확
* 동일 객체 처리 문제를 이해하기 쉬움
* 유지보수성이 높음
* 현대 컴파일러가 불필요한 임시 저장을 충분히 최적화 가능

따라서:

```text
XOR Swap
→ XOR의 대수적 성질을 보여주는 학습 예제

Temporary Variable Swap
→ 일반적인 실제 코드
```

로 구분하는 것이 적절.

## 비트 연산과 값의 의미

비트 연산자는 정수의 수학적인 의미보다 **각 비트 위치의 패턴**에 초점을 맞춤.

예:

```text
0x41
```

ASCII 문맥에서는:

```text
'A'
```

정수 문맥에서는:

```text
65
```

비트 연산에서는:

```text
0100 0001
```

이라는 비트 벡터로 다룸.

```text
Value
  ↓
Bit Pattern
  ↓
Bitwise Operation
```

이는 Chapter 1의 **Bits + Context** 관점과 다시 연결됨.

## 개발할 때 왜 중요한가

### 플래그 관리

하나의 정수에서 여러 Boolean 상태를 표현할 수 있음.

예:

```c
#define READ    0x01
#define WRITE   0x02
#define EXECUTE 0x04
```

권한 설정:

```c
flags |= READ;
```

권한 확인:

```c
flags & READ
```

권한 제거:

```c
flags &= ~READ;
```

* 운영체제 권한
* 장치 레지스터
* 네트워크 프로토콜
* 그래픽 API
* 파일 포맷

등에서 빈번하게 사용.

---

### 하드웨어 레지스터 조작

임베디드 시스템에서는 하나의 정수 내 각 비트가 서로 다른 하드웨어 상태를 표현하는 경우가 많음.

```text
Bit 0 → Enable
Bit 1 → Interrupt
Bit 2 → Error
Bit 3 → Ready
...
```

비트 연산을 사용하면 특정 상태만 변경 가능.

```text
Register
   ↓
Mask
   ↓
Desired Bits Only
```

---

### 바이너리 데이터 처리

프로토콜이나 파일 포맷에서는 하나의 바이트에 여러 필드를 압축해서 저장하기도 함.

예:

```text
10110110
│ │  │
│ │  └─ Field C
│ └──── Field B
└────── Field A
```

필요한 비트만 마스크로 추출하여 해석 가능.

## 이후 학습과의 연결

앞 절:

```text
Boolean Algebra
      ↓
AND / OR / XOR / NOT
```

이번 절:

```text
Boolean Operations
       ↓
C Bitwise Operators
       ↓
~  &  |  ^
```

다음 단계에서는 비트 위치 자체를 왼쪽이나 오른쪽으로 이동시키는 **Shift Operation**으로 연결.

```text
Bitwise Operations
        ↓
Shift Operations
        ↓
Integer Encoding
        ↓
Integer Arithmetic
```

특히 마스크 생성에서는 shift와 비트 연산을 함께 사용하는 경우가 많음.

```c
1u << k
```

를 이용하면 특정 위치 `k`에만 `1`이 존재하는 마스크 생성 가능.

```text
k = 3

00000001
   ↓ << 3
00001000
```

이후 비트 추출·설정·제거의 핵심 패턴으로 활용.

---

## 정리

* C는 `~`, `&`, `|`, `^` 비트 수준 연산자 제공
* 각 비트 위치에 독립적으로 Boolean 연산 수행
* 정수 타입에 적용할 수 있지만 실제 연산에는 C의 정수 승격과 타입 변환 규칙도 적용
* 작은 정수 타입에 `~`를 적용할 때 특히 Integer Promotion 주의 필요
* 비트 패턴을 직접 다룰 때는 unsigned 타입이 이해하기 쉬움
* AND는 특정 비트를 선택하거나 제거하는 데 활용
* OR은 특정 비트를 `1`로 설정하는 데 활용
* XOR는 특정 비트를 반전하는 데 활용
* 마스크는 원하는 비트만 선택하거나 변경하기 위한 핵심 기법
* XOR의 `x ^ x = 0`, `x ^ 0 = x` 성질을 이용해 임시 변수 없는 값 교환 가능
* XOR swap은 동일한 메모리 위치를 두 인자가 가리키면 값이 `0`이 되는 문제 존재
* 실제 코드에서는 일반적인 임시 변수 방식의 swap이 더 명확하고 안전
* 비트 연산은 이후 shift, 정수 표현, 시스템 수준 데이터 조작의 기반

> **C의 비트 연산자는 정수를 하나의 숫자로만 보지 않고, 여러 개의 독립적인 비트로 이루어진 벡터로 직접 조작할 수 있게 하는 도구.**
